# Food AI — Internacionalização (i18n) com 3 idiomas + seletor

- **Status:** Validated
- **Branch:** task/fix-security-concurrency (feature branch atual; base = origin/update_frontend)
- **Goal:** Adicionar internacionalização ao frontend React com **3 idiomas** (Português `pt`, English `en`, Español `es`) e um **seletor de idioma** que permita alternar entre eles, persistindo a escolha. Objetivo: "done" = toda a UI está traduzível via `t()`, o app permite trocar de idioma em runtime, e a escolha é lembrada (localStorage) e aplicada desde o carregamento.
- **Context:** Frontend em React 19 + Vite + React Router 7 (`frontend/web`). Não há lib de i18n instalada. Há 12 componentes com texto de UI: `Dashboard`, `Friends`, `Generate`, `Header`, `History`, `Login`, `OAuthSuccess`, `Privacy`, `Profile`, `Register`, `Terms`, `UserProfile`. O app já usa providers (AuthContext, PresenceContext) e helper `api.js`. A UI hoje é uma mistura de pt-BR e en. Build do frontend ocorre dentro do container (Dockerfile multi-stage: `npm ci` + `npm run build`), servido por nginx em `https://localhost:8443`. Decisão: usar `react-i18next` + `i18next` com `initReactI18next`, resources locais (npm bundle, sem HTTP backend), detecção de idioma + persistência via localStorage. Config de segredo/28/etc não afeta; somente frontend.
